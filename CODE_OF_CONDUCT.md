# Code of Conduct

We are committed to a welcoming, harassment-free community. Be respectful,
focus criticism on the work, and do not disclose private information.

Maintainers may moderate contributions that violate these expectations.
Reports should be sent privately to the maintainers listed in
[MAINTAINERS.md](MAINTAINERS.md). Security vulnerabilities must follow
[SECURITY.md](SECURITY.md).
